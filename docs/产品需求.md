# cc-bar 产品需求

> 描述当前已交付版本的功能范围与边界。新需求迭代时以本文为准；与代码不一致以代码为准并同步回这里。

---

## 0. 产品定位

- **形态**：常驻菜单栏的小工具（Accessory App，默认不占 Dock；打开主窗口期间临时显示 Dock 图标，关闭后恢复）。
- **平台**：macOS 14 Sonoma+（依赖 SwiftUI `MenuBarExtra(.window)`、`@Observable`、`SMAppService`）。
- **设计**：以 macOS HIG 为底座，关键信息层（百分比、进度、KPI、HUD）按设计稿落地自绘组件；非关键层（Picker / Toggle / DatePicker / TabView / Material）全部用系统默认。
- **一句话价值**：装上它 → 不打开 CLI 也能随时看到 Codex / Claude Code / Antigravity 还剩多少 5 小时与周窗口额度，并查看 Codex / Claude Code 的本地 Token 与费用。

---

## 1. 账号自动识别

- 启动时扫描本机已有的 Codex / Claude Code 凭据与 Antigravity 安装状态：
  - Codex：`~/.codex/auth.json`。支持两种凭据形态：① OAuth 模式（`tokens.*`，解析 JWT 拿邮箱 / plan / accountId，到期自动续期）；② personal access token 模式（顶层 `personal_access_token`，即 ChatGPT Team/Enterprise 后台创建的 Codex 访问令牌，不透明、不续期，身份由 `wham/usage` 响应回填）。导入「其他 Codex 账号」时也接受这两种形态的粘贴。
  - Claude：先读 `~/.claude/.credentials.json`；不存在则读 macOS Keychain 通用密码项 `Claude Code-credentials`（service name）。邮箱兜底从 `~/.claude.json` 顶层 `oauthAccount.emailAddress` 读取。
  - Antigravity：检测官方 App / IDE 的本地 `language_server`。只在进程运行时通过 loopback 读取 `Claude + GPT models` 组和 `Gemini Models` 组的 5H/WK 剩余额度（Gemini 仅在 Popover 中作为子行展示，不影响菜单栏和悬浮窗）。不读取或保存 Google OAuth 凭据。
- 不做 App 内登录流程。前提：用户已经在终端跑过 `codex login` / `claude` 登录。
- 用户可在「设置 → 账号」勾选要显示的服务；关闭后该服务在菜单栏、Popover、悬浮窗、统计中均不出现，也不查询其 API。
- 首次启动若不存在 `~/.claude/.credentials.json`，且尚未提示过，会先弹一次说明性 Alert（"接下来 macOS 会弹 Keychain 授权窗口，请选择始终允许"），再触发系统 Keychain 弹窗。

## 2. 菜单栏标签

- 标签是模板图像（template NSImage），自适应深浅菜单栏。
- 顺序固定：**Codex → Claude Code → Antigravity**。
- 每段为 `<服务 logo>  <百分比>`：
  - Logo 用项目内置的 `codex.svg` / `claude.svg` / `antigravity.svg`（菜单栏会做模板化变灰）。
  - 百分比用 `monospacedDigit`。
- 设置项：
  - 显示哪个服务（Codex / Claude / Antigravity，可分别开关）。
  - 显示哪个额度窗口：5 小时 / 周窗口 / 两者（`5h/1w` 斜杠拼接）。
- 都关闭时仍保留一个占位 logo，避免菜单栏完全消失。

## 3. Popover 总览

- 点击菜单栏图标弹出宽 340pt 的窗口。
- 顺序：Codex → Claude → Antigravity（每个服务一个 block，用 Divider 分隔）。
- Header 一行：标题「Usage / 用量」+ 副标题（最近一次刷新相对时间）+ 状态点（live / stale / offline）+ 三个一级图标按钮（刷新 / 统计 / 设置）+ ⋯ kebab 菜单（退出）。
- 每个 block 字段：
  - 服务 tile + 服务名 + 副标题（Provider · Plan）。
  - 5 小时窗口：38pt 剩余百分比 + 进度条 + 重置倒计时；Codex / Claude 额外显示「今日 cost」+「本周 cost」，Antigravity 不显示费用，但展示 Gemini 独立额度的 GM（5h）/ GW（周）简洁进度行。
  - 周窗口：缩小版进度条 + 百分比 + 重置时间。
  - 失败时下方两行内短文案提示。
- 关闭全部服务时显示"未启用任何服务 / 到「设置 → 账号」开启"占位。
- 状态点阈值：以当前额度刷新间隔为基准，age ≤ 1.5× 间隔为 live，≤ 3× 为 stale，超过为 offline。

## 4. 桌面悬浮窗（Floating HUD）

- 设置里可勾选「显示悬浮窗」。
- 默认按已启用服务逐行展示：
  - 第一行：Codex 5 小时剩余百分比（18pt tile + 进度条 + 大字百分比）。
  - 第二行：Claude 5 小时剩余百分比。
  - 第三行：Antigravity `Claude + GPT models` 5 小时剩余百分比。
- 行可分别开关，结果只显示一行 / 全部隐藏。
- 样式：14pt 圆角 + `.popover` material + 0.5pt hairline 描边；无标题栏；不抢焦点；可拖动；始终置顶。
- 位置记忆：拖动后写回 UserDefaults；屏幕外重启时回落到默认右上角。
- 拖到距屏幕边缘 20pt 以内自动吸附到该边。

## 5. 自动后台刷新

- 后台两条独立循环：
  - 额度 API 循环：默认 2 分钟，可选「1m / 2m / 3m / 5m / 10m」。
  - 本地 JSONL 扫描循环：默认 2 分钟，可选「1m / 2m / 3m / 5m / 10m」。
- 端点：
  - Codex：`GET https://chatgpt.com/backend-api/wham/usage`，带 `ChatGPT-Account-Id` 头。
  - Claude：`GET https://api.anthropic.com/api/oauth/usage`，带 `anthropic-beta: oauth-2025-04-20`。
  - Antigravity：本机 `https://127.0.0.1:<port>/exa.language_server_pb.LanguageServerService/RetrieveUserQuotaSummary`，CSRF token 仅从官方进程参数读取并保留在内存。
- 限流策略：
  - 同一服务两次成功之间至少 60 秒，周期性触发若间隔不足直接跳过。
  - 收到 429 后该服务进入 10 分钟退避，期间所有请求短路。
  - 手动「立即刷新」可绕过 60s 节流但仍遵守 429 退避。
- Claude API 失败且**完全没有可展示缓存**时，手动刷新会触发一次 Claude CLI 兜底（启动 `claude` 进程，向其 stdin 写入 `/usage`，解析输出），CLI 兜底也有独立 10 分钟冷却。
- Token 续期：Codex / Claude 双方均在 access_token 距离过期 5 分钟内时用 refresh_token 自动续期，并把新 token 写回原存储位置（文件或 Keychain）。
- 启动行为：先读本地额度缓存让 UI 立刻有数；首次刷新由调度器节奏触发；网络或本地服务失败保留已有快照，仅以小字提示。
- Antigravity 数据源按 App → IDE 顺序回退；App 提供完整 5H/WK，IDE 兜底可能只有 5H。绝不自动启动 `agy` CLI。

## 6. 本地用量统计

- 数据源：纯本地 JSONL，**额度 API 不返回历史数据**。
  - Claude：`~/.claude/projects/**/*.jsonl`，解析 `type=assistant` 行。同一 `message.id` 跨文件全局去重（sidechain / subagent 会重复引用同一条），seen 集合上限 20000。
  - Codex：`~/.codex/sessions/**/*.jsonl` + `~/.codex/archived_sessions/**/*.jsonl`，按 `turn_context` 提供的当前 model 给随后的 `event_msg/token_count` 打标签；token 用 `payload.info.last_token_usage`，billable input = `input_tokens − cached_input_tokens − cache_write_tokens`。`cache_write_tokens` 兼容顶层及 token details；当前本地日志未提供时按 0，不推测。
- Antigravity 不提供同口径的本地 Token / cost 日志，因此不进入本地用量统计、服务筛选或 Timeline。
- 增量逻辑：每个文件按 `mtime + offset` 维护 watermark，未变化直接跳过；文件被截断时 offset 归零重扫，去重由全局 seen 兜底。
- 聚合：按 `(day, app, model)` 三元组在内存中累加；持久化到 `usage-rollup.json`。
- 对话聚合：同一批扫描同时按 `(conversation, day, model)` 聚合并写入 `conversation-rollup.json`，不保存聊天正文。Codex 以 `session_meta.id` 为对话 ID，标题优先取 `~/.codex/session_index.jsonl`；Claude 以 `sessionId` 为对话 ID，相同 sessionId 的 subagent / sidechain 合并到主对话，标题优先取 `~/.claude/history.jsonl`。
- 对话项目归属：以规范化完整路径作为项目身份；存在的路径优先归一到 Git 根目录，Claude 同时参考 history project、主会话 cwd 与顶层项目容器，子任务目录不能覆盖主项目。已删除项目保留历史归属；用户主目录 / 根目录归为“无明确项目”，CCBar probe / wakeup 归为“CCBar 系统任务”。同名不同路径不合并。
- 对话费用是按模型 API 公开价格折算的**等值估算**，不是 Codex / Claude 订阅实际账单；未定价模型明确标记，不显示成真实 `$0`。
- 价格表：GPT-5.6 阶梯价（覆盖 `gpt-5.6`/Sol 别名、`gpt-5.6-sol`、`gpt-5.6-terra`、`gpt-5.6-luna`，官方短/长上下文费率折算，完整输入 `>272,000` 时该次请求全部用长上下文价）、Claude Sonnet 5 分段生效价等少数需要特殊规则的模型继续手工维护在 `Core/Usage/Pricing.swift`，不受远端数据影响。缓存写入字段本地日志未提供时费用估算为 0，不推测。其余模型（多数 Codex / Claude / DeepSeek 型号）由内置价格表 + 后台自动拉取的 LiteLLM / models.dev 远端价格目录共同提供：App 启动后台静默刷新（24 小时一次，失败退避重试，不阻塞任何本地功能），远端已收录的新模型或调价无需发新版即可在下次扫描生效；无网络或远端不可用时自动降级为内置表，不影响离线使用。命中不到任何价格源的模型视为「未定价」（区别于真实 $0），token 仍记录，不计入金额汇总；金额统计口径不受未定价模型影响。模型名归一化：剥 `openai/`/`deepseek/` 前缀、`@YYYYMMDD` 或 `-YYYY-MM-DD` 日期后缀，本地与远端目录共用同一套规则。

## 7. 主窗口 — 统计

- 主窗口为普通 macOS 窗口，最小 800×520，含顶部 TabView：统计 / 设置。
- 入口：Popover 的统计 / 设置图标、菜单栏的 ⌘1 / ⌘, 命令、⌘R 触发立即刷新。
- 统计 tab：
  - 侧栏：服务过滤（All / Codex / Claude Code），View 切换（Overview / Conversations / Timeline）。
  - 顶部 segmented Picker：Today / Yesterday / Week / Month / Year / 7d / 30d / All / Custom。
  - 自定义：两个 DatePicker（仅在 Custom 时出现）。
  - KPI 一排 4 张：总 tokens / 总花费 / Codex 花费 / Claude 花费；每张带相对上一同长度区间的 delta 百分比。
  - 日趋势：堆叠柱状图（Codex vs Claude），用 SwiftUI Charts。
  - 服务占比：水平条形 + KPI 文本。
  - 当前额度：展示 Codex / Claude / Antigravity 的 5h / 1w 剩余百分比，颜色按状态色逻辑。
  - 按模型明细：分服务列出 model · 调用次数估算 · tokens · cost。
  - Conversations：左侧列表按所选时间范围展示对话标题、项目、服务、模型、请求数、Tokens 与 API 等值估算费用；支持 Codex / Anthropic 服务筛选、单项目筛选、标题/项目搜索、最近/Tokens/费用排序和每次 200 条渐进加载。项目菜单区分正常、已不存在、无明确项目和 CCBar 系统任务。右侧详情固定展示该对话全部时间的四项 Token、缓存命中率、四项费用、模型构成与完整时间信息。对话页刷新只扫描本地日志，不等待额度或服务状态网络请求。
  - Timeline：展示今日各账号 5H 额度变动。只显示发生变化的时间点；同值刷新仅更新基准，不进入曲线和表格。每个账号独立分区，顺序为 Codex 主账号 → Codex 副账号 → Claude Code。

## 9. 首次启动引导（Onboarding）

- 首次启动检测到 `SettingsStore.didCompleteOnboarding == false` 时弹出 4 步窗口（620×520，`.regularMaterial`）：
  1. Welcome：标题 + 简介。
  2. Detect accounts：展示自动识别的 Codex / Claude 账号以及 Antigravity 安装状态。
  3. Configure：菜单栏窗口 / 悬浮窗开关等关键设置一次性勾选。
  4. Ready：完成，按钮可直接进入"统计"或关闭。
- 完成后写入 `didCompleteOnboarding=true`，后续启动不再展示。

## 12. 一期明确不做

- 不做 App 内 OAuth 登录。
- 不做浏览器 Cookie 自动导入。
- 不做 WebView 抓 dashboard DOM。
- 不做 Copilot / 国产 Token Plan。
- 不上 Mac App Store（沙盒会拦住 `~/.claude` / `~/.codex` 读取）。
- 不做组织级 Admin API。
- 不做额度告警通知。

`claude /usage` 的 CLI 兜底当时被列为「一期不做」，实际作为最后一道兜底已经做了；只在 Claude API 失败且无可展示缓存的手动刷新场景启用，不替代主路径。

## 13. 风险 / 待持续关注

1. **非公开接口稳定性**：`wham/usage` / `oauth/usage` / Antigravity 本地 Language Server 字段可能随时调整，解析器需要保持容错；Antigravity 升级后可能暂时显示旧缓存和接口错误。
2. **Keychain 弹窗**：首次读 `Claude Code-credentials` 系统会弹一次授权窗，引导文案已加。
3. **价格表漂移**：当前对齐 cc-switch / CodexBar 2026 上半年价位；模型迭代后需要同步。
4. **JSONL 量级**：长期使用后 `~/.claude/projects` 可达数百 MB；增量 watermark + seen ID 上限保证启动 / 扫描时间可控，但 seen 集合上限 20000 时若历史窗口超过该长度会有边缘重复风险。
5. **签名与公证**：发布前需 Apple Developer 证书；当前开发期未签名，README 标注「右键打开」。
