### 1.3 Header

- **容器**:HStack(spacing 4),padding `14pt 上 / 12pt 左右 / 12pt 下`(到 separator)。
- **左侧**(VStack,line-height 1.1):
  - `Usage` — 13pt .semibold
  - `用量 · refreshed 32s ago` — 11pt secondary
    - `refreshed {n}s ago` / `{n}m ago` / `{n}h ago`,取可见监控源中**最近**一次成功时间;无成功时显示 `用量 · 等待数据`。
- **右侧**(HStack,spacing 4):
  1. **status dot** — 7pt 圆点(live/stale/offline),颜色按 设计风格 §4.3,hover tooltip `Live · 在线` 等。
  2. **Quota window toggle** — 文字按钮,显示第一个可见 provider 当前窗口的标签(`5H` / `WK`,Ollama 为 `MO`),同尺寸按钮。点击在主副窗口之间切换菜单栏状态数字与 Floating HUD 窗口,选择持久化到 `ccbar.settings.menuBarWindow`(raw 值仍为 `fiveHour` / `weekly` / `both`)。Popover 卡片不受影响,始终列出全部窗口。
  3. **Refresh** — `arrow.clockwise` 13pt,同尺寸按钮。点击触发 `appState.refreshNow()`,图标旋转 360° / 700ms ease-in-out。
  4. **Open Statistics** — `chart.bar.xaxis + Stats/统计`,按钮 `54pt × 22pt` 圆角 5pt,hover 浅灰背景(`Color.primary.opacity(0.08)`)+ 手型光标。点击 `openWindow(id: "main")` 并切到 Stats tab。
  5. **Settings** — `gearshape` 13pt,同尺寸按钮。点击打开主窗口(当前与 Statistics 共用入口,落到 `appState.mainTab` 当前所记的 tab;⌘, 命令会显式切到设置 tab)。
  6. **Quit** — `power` 13pt,同尺寸。点击 `NSApp.terminate(nil)`,hover tooltip `Quit · 退出`。

> 设计依据:用户反馈一级操作(设置 / 刷新 / 统计 / 退出)藏在 kebab + footer 里不直观,统一拉到顶部图标行,降低点击层级。Quit 早期收在 `ellipsis` 菜单需要点两次,后续也拉平为一级图标。

- **separator**:0.5pt 全宽,`.separatorColor`。

### 1.3.1 低额风险摘要

- **出现条件**:任一可见账号的 `5H` 或 `WK` 窗口剩余 `≤20%`。
- **选择规则**:只显示当前最紧张的一项；比较所有可见 provider 下每个账号的主 / 副窗口剩余百分比，取最低值。标题格式 `<Provider> · <账号短名> · <窗口标签>`。
- **隐私**:隐私模式下账号短名显示为 `Default` / `Account N`，不显示别名和邮箱。
- **布局**:Header 下方单行浅色状态背景，左侧 `exclamationmark.triangle.fill` 或 `exclamationmark.octagon.fill`，中间两行 `Quota risk` + `账号 · 窗口`，右侧剩余百分比 + 紧凑重置时间。
- **颜色**:图标、标题、百分比走 `statusColor`；背景用同色 10% opacity。

### 1.4 账号卡片(所有 provider 共用,`ServiceBlockView`)

参考 CodexBar 的 menu card:每个账号一张卡,`12pt 上下 / 16pt 左右` padding,VStack spacing 10pt。

#### 1.4.1 Header row(HStack top 对齐,gap 9pt)

| 元素 | 规格 |
|---|---|
| 服务 tile | 22pt × 22pt squircle(6pt 圆角),`Provider.accent` 填充,白色 logo 14pt 居中。详见 设计风格 §11.2。 |
| 名称 + 副标题(同一行,gap 6pt) | `Codex` 13pt .semibold kerning -0.1(`ProviderDescriptor.displayName`)+ 副标题 11pt secondary 75%,中间截断;副标题由 `MonitoredAccount.popoverSubtitle(index:)` 生成:`Default · me@x.com · Pro` / `imported · alias · me@x.com` / `ccpm · work · api.kimi.com · Default`;缺身份时显示厂商名 |
| 刷新状态行(第二行) | 10.5pt tertiary tabular,每秒重算:`Updated 32s ago` / `Refreshing…` / `Waiting for first refresh` / `Refresh failed`;来源非 API 时追加 ` · cache` / ` · Claude CLI` |
| Spacer | — |
| plan 胶囊 | `state.snapshot?.planType ?? identity.plan`,10.5pt .medium secondary,`Capsule` 背景 `secondary.opacity(0.12)`,padding 6/2 |
| 服务状态圆点 | 6pt 圆,顶部下移 5pt。颜色按 statuspage indicator(none 绿 / minor 黄 / major 橙 / critical 红 / maintenance 蓝),`unknown` 或未拉到时不显示。只有 Codex / Claude 有状态页。受设置项 `showServiceStatus` 控制,tooltip 显示 description + 相对更新时间。 |

#### 1.4.2 窗口段(`laneSection`,每个窗口一段,VStack spacing 4pt)

段列表 = `snapshot.allWindows`(主窗口 → 副窗口 → `extra`);还没有快照时按 descriptor 的 `primaryKind` / `secondaryKind` 画占位段。

1. **标题行**(HStack baseline):左 `kind.laneTitle` 12pt .semibold(`Session · 5h` / `Weekly` / `Monthly` / `Opus · weekly` / `Sonnet · weekly` / `MCP · monthly` / `Extra usage · monthly`);右 `QuotaWindow.detail` 10.5pt secondary tabular(有则显示:`139/200 requests` / `$7.50 of $60` / `1000 limit · 600 remaining` / Claude 超额 `$12.34 / $2000.00`)。Claude 的 `Extra usage · monthly` 段没有重置时间,右侧数值行只显示 `N% left`。
2. **进度条**:高 6pt,状态色填充,进度 = `remainingPercent / 100`;无数据时空轨道。
3. **数值行**(HStack baseline):左 `74% left · 剩余 74%` 11.5pt .semibold tabular 状态色(无数据 `--%`);右 `ResetTimeHint` 11pt secondary,每分钟重算,hover 切换相反格式(剩余时长 ↔ 绝对时间)。
4. **节奏行**(仅 `QuotaPace.compute` 非 nil,即窗口有重置时间且已过去 ≥3%):10.5pt tabular:

| 情况 | 文案 | 颜色 |
|---|---|---|
| `deltaPercent > 0` | `Pace: ahead +12%` / `节奏:超前 +12%` | `quotaPaceAheadColor` |
| `deltaPercent < 0` | `Pace: behind -8%` / `节奏:落后 -8%` | secondary |
| `= 0` | `Pace: on track` / `节奏:正常` | secondary |

   后缀:有 `runsOutAt` 时 ` · runs out in 42m` / ` · 预计 42m 后耗尽`,否则 ` · lasts to reset` / ` · 可撑到重置`。

#### 1.4.3 本地用量段(`usageSection`,仅 `usageRoots` 非空的账号)

VStack spacing 3pt:标题 12pt .semibold(`Cost · 花费`,不计费 provider 为 `Tokens · 令牌`)+ 三行 11pt:`Today: ` / `This week: ` / `Last 30 days: `(secondary)+ 值(primary tabular)。值格式:计费 provider `$12.40 · 184k tokens`,不计费 provider `184k tokens`;无数据 `—`。数据来自 `UsageAggregator.totals(accountId:from:to:)`(今日 / 本周一起 / 最近 30 天)。手动导入的 Codex 账号没有本地日志,不显示此段。

#### 1.4.4 操作行(`actionRow`,每张卡片都有)

一行 10.5pt .medium secondary 文字按钮,` · ` 分隔,hover 手型光标:

| 按钮 | 出现条件 | 动作 |
|---|---|---|
| `Dashboard · 用量面板` | `MonitoredAccount.dashboardURL != nil`(五个 provider 都有;GLM 按接口 host 选 bigmodel.cn / z.ai) | `NSWorkspace.open` |
| `Status · 状态页` | `ProviderDescriptor.statusPageWebURL != nil`(Codex → status.openai.com,Claude → status.claude.com) | `NSWorkspace.open` |
| `Terminal · 终端` | `source` 为 `.ccpm` 且 provider ≠ Codex | `CCPMCommand.openInTerminal`:Terminal.app 新窗口执行 `ccpm run <profile>`(首次弹 macOS 自动化授权) |
| `Set default · 设为默认` | 同上,且 `identity.isDefaultProfile == false` | `CCPMCommand.setDefault`(20s 超时),成功后 `appState.rediscover()` |

失败时(找不到 `ccpm`、非零退出、超时)在操作行下方追加一行 10.5pt `quotaPaceAheadColor` 错误文案(`actionError`),下一次点击时清空。

#### 1.4.5 分隔

- 同一 provider 的卡片之间,以及 provider 分区之间:0.5pt 横线,**左右各 inset 16pt**。
- 最后一张卡片之后无 footer,Popover 在此结束(由系统的 `NSPopover` 圆角承接底边)。

#### 1.4.6 空状态 / 错误状态

- 账号无快照且无错误:占位窗口段显示 `--%` + 空轨道,刷新状态行 `Waiting for first refresh`。
- `state.error != nil`:卡片底部追加一行 10.5pt `quotaPaceAheadColor`,显示错误首行(`shortError` 截断 110 字)。窗口段按最后一次成功快照继续显示(快照不清空)。凭据不可用(`.unavailable`)的账号错误即原因,例如 `no API key in ccpm keystore`;Ollama 未粘贴 Cookie 显示 `missing cookie; paste one in Settings`。
- provider 在 Settings 里被关闭(`enabledProviders` 不含它):其所有账号不渲染,且不进入低额风险摘要。
- 没有任何可见 provider:Popover 只显示 header + 中部一段 `No services enabled · 未启用任何服务` caption,提示去 Settings。

### 1.5 Footer(已废弃)

> 原方案的 footer(左侧 `Open Statistics` 按钮 + 右侧 refresh + kebab)已**完全移除**。所有一级操作上移到 §1.3 Header 的图标行,刷新进度通过 header 刷新图标自身旋转 + disabled 表达。本节保留仅为历史参考,新实现不要再引入 footer。

### 1.6 交互

| 触发 | 行为 |
|---|---|
| 点 header `chart.bar.xaxis + Stats/统计` | `openWindow(id: "main")`,切到 Stats tab 并置前 |
| 点 header `arrow.clockwise` | 触发 `appState.refreshNow()`,旋转 360° / 700ms,最低保持 0.5s 防闪 |
| 点 header `gearshape` | 打开主窗口并切到 Settings tab |
| 点 header `power` | `NSApp.terminate(nil)`,退出 App |
| 点账号卡片任意空白 | 暂不响应(后续可定位主窗口到对应账号) |
| 点 Popover 外 | Popover 关闭(系统默认) |
| Esc | Popover 关闭(系统默认) |
| ⌘R(focus 在 Popover) | 触发 refresh |
| 鼠标悬停任意图标按钮 | 浅灰圆角背景 + 手型光标(详见 设计风格 §11.9) |
| 鼠标悬停 reset 时间 | 行内切换相反格式:设置为剩余时长时显示具体时刻(当天 `HH:mm`,跨天 `MM-dd HH:mm`);设置为具体时间时显示剩余时长。hover 热区略大于文字本身,避免鼠标遮挡数字才触发。 |

## 2. Floating HUD

### 2.1 整体规格(默认变体:Two-row pill)

| 项 | 值 |
|---|---|
| 宽 | auto,最小 190pt |
| 高 | auto(两行 pill 约 50–60pt) |
| 圆角 | 14pt |
| 材质 | `.hudWindow`(`NSVisualEffectView`,`blendingMode: .behindWindow`) |
| 背景 alpha | 浅 0.58 / 深 0.62(material 自带) |
| 阴影 | `0 10 28 rgba(0,0,0,0.28)` + inset 0.5pt `rgba(255,255,255,0.1)` 高光(material 自带 + SwiftUI 叠一层 fallback 见 设计风格 §7) |
| 内边距 | 10pt 上下 / 14pt 左右 |

### 2.2 内容结构(variant 1)

VStack,spacing 7pt。每个已勾选的 provider 一行(`effectiveFloatingProviders ∩ presentProviders`,顺序即 provider 顺序):

```
[●]  ████████░░░░░░░░░░  5H  [42%]
[●]  ███████████████░░░  5H  [78%]
[●]  ██████████████████  MO  [88%]
 18pt    flex,4pt bar    22pt  34pt
```

| 元素 | 规格 |
|---|---|
| 左侧 logo tile | `ServiceTile` 18pt 圆角 5pt,`Provider.accent` 填充 + 内嵌 logo 12pt(`Resources/Logos/<provider>.svg`),加载失败时回退 `fallbackGlyph` |
| 中间 bar | 高 4pt,圆角 2pt,状态色填充 + `.quaternarySystemFill` 轨道,flex 1(最小宽 56pt) |
| 窗口标签 | `5H` / `WK` / `MO` 9pt .semibold quaternary,宽 22pt 右对齐(取该 provider 当前窗口的 `kind.shortLabel`) |
| 右侧百分比 | 13pt .semibold tabular kerning -0.3,状态色(见 设计风格 §4.3),最小宽 34pt 右对齐 |
| 行内 spacing | 8pt(tile / bar / 标签 / 百分比 之间) |

进度 = 该 provider 聚合快照(`appState.monitorSnapshot(for:)`,多账号取剩余最低者)当前窗口的 `remainingPercent / 100`;主 / 副窗口跟随 `settings.menuBarWindow`。bar + 文字均按 设计风格 §4.3 四档状态色显示。

### 2.3 备选变体(Settings 提供切换)

prototype 还画了另外 7 个变体,Settings → Floating HUD → Style 下拉里全部提供:

| Variant | 名称 | 适用场景 |
|---|---|---|
| 1(默认) | Two-row pill · 两行胶囊 | 标准 |
| 2 | Stacked numbers · 大数字 | 不要 bar,只看百分比 |
| 3 | Dual mini rings · 双小环 | 视觉化偏好者 |
| 4 | Ultra-thin · 极简 | 屏幕空间紧张 |
| 5 | Single service · 单服务 | 只关心 Claude / 只关心 Codex |
| 6 | Horizontal slim · 横向窄条 | 顶部 / 底部窄边贴边 |
| 7 | 5h + Week verbose · 详细模式 | 同时看 5h 和周 |
| 8 | No chrome · 无背景纯文字 | 极致简约,文字带阴影直接铺桌面 |

实现:每个 variant 一个 `View`,在 `FloatingContentView` 里按 settings 切换。

### 2.4 交互

| 触发 | 行为 |
|---|---|
| 整个 HUD 区域拖动 | 移动位置,松手时持久化到 SettingsStore |
| 拖至屏幕边 20pt 内 | 吸附到边缘 |
| 鼠标进入 / 离开 | 透明度根据 Settings → Opacity when idle 切换(idle 0.7 → hover 1.0,150ms ease) |
| 点击单行 | 暂不响应(规划中:跳转主窗口对应服务 scope) |
| 右键 | 显示原生菜单:`Hide HUD · 隐藏` / `Settings · 设置` |

### 2.5 浅深色

- **不写**手动 background;`NSVisualEffectView(.hudWindow)` 在两种 appearance 下自动给出 prototype 的两套 alpha + blur。
- 文字颜色:标签 `.secondary`、百分比状态色(见 设计风格 §4.3 / §12.1)。
- **不**加 strokeBorder。当前 `Floating/FloatingContentView.swift:35-38` 的 `strokeBorder(opacity 0.08)` 应去掉。

### 2.6 数据来源对照

| UI 字段 | 数据源 |
|---|---|
| 每行百分比 + bar | `appState.monitorSnapshot(for: provider)` 的主 / 副窗口 |
| 显示 / 隐藏 | `settings.floatingEnabled` |
| 哪些 provider | `settings.floatingProviders`(与 `enabledProviders` 取交集,再与 `appState.presentProviders` 取交集) |
| 窗口选择 | `settings.menuBarWindow` |

## 6. 已实现 / 可拓展

本文档描述的界面均已实现。下面只记录可拓展但尚未做的方向,新需求落地时再决定:

- Floating HUD 备选变体(prototype 共 8 种,当前只实现默认的 Two-row pill)。
- Breakdown 后续可增加 CSV 导出和按账号来源拆分;当前为本地聚合桶明细表。
- Floating HUD 单击行跳转主窗口对应服务 scope。
- HUD idle 透明度滑杆(prototype 设计有,当前仍是恒定 1.0)。
- 通知的更多事件(例如节奏超前到一定阈值);当前只有低额 / 用尽 / 重置三类。

新增界面或大幅修改现有界面时,优先沿用本文档定义的尺寸 / 间距 / 配色 / 状态规则,改完后回头同步本文。
